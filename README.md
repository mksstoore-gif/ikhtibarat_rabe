# اختبارات الصف الرابع

تطبيق Flutter عربي بسيط لاختبارات الصف الرابع الابتدائي، مخصص للاستخدام الشخصي.

## النسخة 0.4

- اسم التطبيق على أندرويد: **اختبارات الصف الرابع**.
- خلفية بيضاء وواجهة أبسط.
- شاشة رئيسية مختصرة مع المواد المتاحة.
- إنشاء الاختبار أصبح على خطوات واضحة: المادة، الدروس، شكل الاختبار، المستوى، العدد.
- شاشة الاختبار تعرض سؤالًا واحدًا في كل مرة.
- أسئلة صح/خطأ تظهر بزرين كبيرين واضحين.
- الاختيارات تظهر كمربعات اختيار كبيرة بدل القوائم القديمة.
- PDF أعيد تصميمه ليشبه ورقة اختبار مدرسية: اسم الطالب، المادة، التاريخ، الدرجة، ومربعات أمام الإجابات.
- نسخة الطالب ونموذج الإجابة وPDF كامل.
- بنوك أسئلة مفعلة للرياضيات، لغتي الجميلة، العلوم، الدراسات الاجتماعية، والدراسات الإسلامية.
- عناوين الدروس مأخوذة من الكتب الرسمية المرفوعة للمشروع.
- الأسئلة التدريبية أصلية وليست نسخًا حرفية من أسئلة الكتب.
- القرآن الكريم مستبعد حسب إعداد المشروع.
- لا تسجيل دخول ولا Firebase ولا خادم؛ البيانات محلية على الجهاز.
