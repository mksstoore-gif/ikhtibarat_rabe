# اختبارات الصف الرابع

تطبيق Flutter عربي Premium لاختبارات الصف الرابع الابتدائي، مخصص للاستخدام الشخصي.

## النسخة 0.5 Premium

- واجهة عربية RTL بتصميم فاخر وموحد.
- لوحة رئيسية جديدة تعرض آخر نتيجة، المتوسط، أفضل نتيجة، والمواد.
- منشئ اختبار جديد من 5 خطوات: المادة → الدروس → الإعدادات → بيانات الورقة → المراجعة.
- شاشة حل سؤال بسؤال مع مؤشر تقدم وعدّاد للإجابات.
- نتيجة مرئية بنسبة مئوية وتصنيف للأداء.
- شاشة مستوى الطالب تعرض مؤشر الإتقان وتحليل المهارات حسب الدروس.
- سجل نتائج مصمم بشكل احترافي.
- إدارة الدروس المدروسة بواجهة أوضح.
- PDF: نسخة طالب + نموذج إجابة + ملف كامل.
- لا تسجيل دخول ولا Firebase ولا خادم؛ البيانات محلية على الجهاز.
- المواد المفعلة: الرياضيات، لغتي الجميلة، العلوم، الدراسات الاجتماعية، الدراسات الإسلامية.
- القرآن الكريم مستبعد حسب إعداد المشروع.
- عناوين الدروس مأخوذة من ملفات المنهج الرسمية المعتمدة للمشروع.
- الأسئلة التدريبية أصلية ومحلية داخل التطبيق.
