# اختبارات رابع — v0.3

تطبيق Flutter عربي محلي لاختبارات الصف الرابع الابتدائي، الفصل الدراسي الأول 1448هـ / 2026–2027م.

## الموجود الآن
- عربية RTL وMaterial 3.
- فهارس الدروس من الكتب الرسمية المرفوعة: لغتي، الرياضيات، العلوم، الدراسات الاجتماعية، الدراسات الإسلامية.
- القرآن الكريم مستبعد حسب متطلبات المشروع.
- ولي الأمر يحدد الدروس التي تمت دراستها، ولا يسمح التطبيق بإدخال درس غير محدد في الاختبار.
- بنك أسئلة رياضيات محلي أصلي: 36 سؤالًا لكل درس مدعوم حاليًا، بدون نسخ أسئلة الكتاب حرفيًا.
- اختيار الدروس ونوع الأسئلة والصعوبة وعدد الأسئلة.
- اسم الطالب وعنوان الاختبار.
- حل وتصحيح وحفظ النتائج في SQLite.
- سجل الاختبارات وتتبع المهارات.
- PDF عربي محلي: نسخة الطالب، نموذج الإجابة، أو ملف كامل يجمع النسختين.
- Workflow جاهز في GitHub Actions لفحص المشروع وبناء APK.

## سياسة الدقة
عنوان الدرس لا يضاف إلا من الكتب الرسمية المرفوعة. الأسئلة التدريبية التي ينشئها التطبيق أصلية ومبنية على مهارات الدرس، وليست أسئلة منسوبة لوزارة التعليم. أي درس لم يجهز له بنك أسئلة يبقى ظاهرًا في الفهرس لكنه مقفل في منشئ الاختبار.

## الخصوصية
لا تسجيل دخول، لا Firebase، لا خادم. البيانات والنتائج محلية على الجهاز.

## بناء APK
ارفع المشروع إلى مستودع GitHub ثم شغّل Workflow باسم `Build Android APK`. بعد نجاحه يظهر artifact باسم `app-release-apk`.
